# ChatBot-Anti-Golpe
Chat Anti-Golpe em Python que usa a API Gemini 2.5 Pro para analisar mensagens suspeitas e identificar possíveis golpes. Segue uma persona de detetive, aponta sinais de alerta e orienta o usuário a agir com segurança. Interface simples no terminal com cores e animação.

Chat Anti-Golpe 🔍🛡️

Um assistente feito em Python que utiliza a API Gemini 2.5 Pro para ajudar usuários a identificar sinais de golpes digitais. O chatbot analisa mensagens, destaca riscos e dá conselhos de segurança com base em engenharia social.

🚀 Funcionalidades

Analisa mensagens suspeitas

Aponta sinais de alerta (urgência, links estranhos, pedidos de dados)

Oferece recomendações seguras

Persona de “Detetive Anti-Golpe”

Interface simples pelo terminal com cores e animação

🧠 Tecnologias

Python

Google Generative AI (Gemini 2.5 Pro)

Colorama

▶️ Como usar

Instale as dependências:

pip install google-generativeai colorama


Coloque sua API Key no código

Rode o script:

python ChatBot.py

📌 Observação

O assistente não dá diagnósticos 100% conclusivos — ele aponta possíveis golpes e orienta o usuário a agir com cautela.
